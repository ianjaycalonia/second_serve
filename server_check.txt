Server Status Check

🔍 Check if your XAMPP/Apache server is running:

1. Open XAMPP Control Panel
2. Make sure Apache and MySQL are both running (green indicators)
3. If not running, click "Start" for both services

✅ If both are running, continue with the tests below.

❌ If not running, start them first, then try the tests.

---

📋 **Quick Test Checklist:**

- [ ] XAMPP Control Panel open
- [ ] Apache service running
- [ ] MySQL service running
- [ ] Can access: http://localhost/
- [ ] Can access: http://localhost/Capstone%20Project/debug_tests.html

**After confirming XAMPP is running, visit:**
http://localhost/Capstone%20Project/debug_tests.html
